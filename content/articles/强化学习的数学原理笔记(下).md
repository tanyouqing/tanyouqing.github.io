# Lesson6.随即近似与随机梯度下降
## 罗宾斯-门罗算法（RM算法）
介绍：

+ 背景：需要求解方程：$ g(w) = 0 $
+ 面临问题：函数g的表达式未知，只知道函数输入和输出，且输出值可能包含噪声：$ \tilde{g}(w, \eta) = g(w) + \eta $
+ 求解算法：$ w_{k+1} = w_k - a_k \tilde{g}(w_k, \eta_k), \quad k = 1, 2, 3, \dots $

**罗宾斯-门罗定理：**

在 RM算法中，如果下面三个条件全部成立：

+ 存在两个常数 $ c_1,c_2>0 $，使得 $ 0 < c_1 \leq \nabla_w g(w) \leq c_2 $ 对于所有的 $ w $ 成立；(a)
+ $ \sum_{k=1}^\infty a_k = \infty $ 且 $ \sum_{k=1}^\infty a_k^2 < \infty $；(b)
+ $ \mathbb{E}[\eta_k | \mathcal{H}_k] = 0 $ 且 $ \mathbb{E}[\eta_k^2 | \mathcal{H}_k] < \infty $，其中 $ \mathcal{H}_k = \{w_k, w_{k-1}, \dots\} $；(c)

那么 $ w_k $ 几乎必然收敛到 $ g(w^*)=0 $ 的根 $ w^* $。

+ 条件(a)要求函数g(w)是一个单调递增的函数，确保g(w)=0的根存在且是唯一的，且梯度不能趋于无穷
+ 条件(b)第二个式子要求$ a_k $要最终收敛到0（确保$ w_{k}-w_{k-1} $收敛），第一个式子要求不能收敛地太快（确保$ w_0 $取值任意）
+ 条件(c)要求误差μ独立同分布
+ $ a_k $在实际中常会被选择为一个小的正数，这样就能很好地利用后面的样本。否则，如果α逐渐收敛到0，那么当k较大时，得到的数据对$ w_k $的影响已经微乎其微了。**此时算法仍然可以在某种意义上收敛**。

## 梯度下降
问题：$ \min_{w} J(w) = \mathbb{E}[f(w, X)], $

解答：$ w_{k+1} = w_k - \alpha_k \nabla_w J(w_k) = w_k - \alpha_k \mathbb{E}\left[ \nabla_w f(w_k, X) \right]. $

+ 批量梯度下降(BGD)：$ w_{k+1} = w_k - \alpha_k \frac{1}{n} \sum_{i=1}^n \nabla_w f(w_k, x_i), $
+ 小批量梯度下降(MBGD)：$ w_{k+1} = w_k - \alpha_k \frac{1}{m} \sum_{j \in \mathcal{I}_k} \nabla_w f(w_k, x_j), $（就算m=n，也与BGD不同，因为是在m样本中随机取样m次，不一定每个样本都被采样到）
+ 随机梯度下降（SGD）：$ w_{k+1} = w_k - \alpha_k \nabla_w f(w_k, x_k). $

当估计值$ w_k $远离最优解$ w^{*} $时，随机梯度下降的收敛与常规梯度下降算法类似；只有当$ w_k $接近$ w^{*} $时，随机梯度下降的收敛才会表现出更多的随机性。

另一种不涉及随机变量的问题描述：$ \min_{w} J(w) = \frac{1}{n} \sum_{i=1}^n f(w, x_i), $

**随机梯度下降是一种特殊的RM算法**

# Lesson7.时序差分方法

> **核心思想**：基于时序差分思想提出新的贝尔曼公式，有了TD target和TD error的概念，进而通过RM算法求解。首先提出基于状态值的时序差分算法，进而用状态值代替就得到Sarsa算法，再将TD target中的动作值改为 $ \max_{a \in \mathcal{A}} q_t(s_{t+1}, a) $ 就得到了Q-learning算法。

## Basics
+ 基础的时序差分方法（状态值）
    - $ \begin{cases}
v_{t+1}(s_t) = v_t(s_t) - \alpha_t(s_t) \left[ v_t(s_t) - \left( r_{t+1} + \gamma v_t(s_{t+1}) \right) \right], \\
v_{t+1}(s) = v_t(s), \quad \text{当 } s \neq s_t,
\end{cases} $
+ TD target：$ r_{t+1} + \gamma v_t(s_{t+1}) \triangleq \bar{v}_t $
    - 意义：该算法的特性来讲，$ \bar{v}_t $是$ v_t(s_t) $的目标值
+ TD error：$ v_t(s_t) - \left( r_{t+1} + \gamma v_t(s_{t+1}) \right) = v(s_t) - \bar{v}_t \triangleq \delta_t $
    - 意义：反映两个状态乃至估计值与真实状态值之间的差异；如果估计值是准确的。TD 误差在期望意义上应该等于0
+ 要想使$ v_t(s_t) $收敛，依旧需要让参数满足RM算法的条件

| TD 方法 | MC 方法 |
| --- | --- |
| 增量式：它可以在得到一个经验样本后立即更新估计值。 | 非增量式：它必须等到一个回合（episode）结束之后，才能用所有经验样本来更新估计值，这是因为它需要计算从某一状态到回合最后的折扣回报。 |
| 持续任务：由于 TD 算法是增量式的，因此它可以处理回合制（episodic）和持续性（continuing）的任务。 | 回合制任务：由于 MC 算法是非增量式的，因此它只能处理回合制任务，这些任务会在有限步后结束。 |
| 自举：TD 算法依赖于自举（bootstrapping），因为状态值/动作值的更新依赖于其先前估计值。因此，TD 算法需要初始值。 | 非自举：MC 算法不是自举的，因为它可以直接估计状态值/动作值，而无需初始值。 |
| 低估计方差：TD 算法的估计方差较低，这是因为它涉及的随机变量较少。例如，要估计动作值 $ q_\pi(s_t,a_t) $，Sarsa 只需要三个随机变量 $ R_{t+1} $、$ S_{t+1} $、$ A_{t+1} $ 的样本。 | 高估计方差：MC 算法的估计方差较高，这是因为它涉及许多随机变量。例如，要估计动作值 $ q_\pi(s_t,a_t) $，MC 算法需要 $ R_{t+1}+\gamma R_{t+2}+\gamma^2 R_{t+3}+\dots $ 的样本。假设每个回合的步数为 $ L $，并且每个状态的动作数等于 $ |\mathcal{A}| $，那么 MC 算法需要的随机变量个数远大于 TD 算法。 |


## Sarsa：动作值估计
$ \begin{cases}
q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t(s_t, a_t) \left[ q_t(s_t, a_t) - \left( r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1}) \right) \right], \\
q_{t+1}(s, a) = q_t(s, a), \quad \text{当 } (s, a) \neq (s_t, a_t),
\end{cases} $

可以与 ε-Greedy 的策略改进方法结合

+ Expected Sarsa：$ \begin{cases}
q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t(s_t, a_t) \left[ q_t(s_t, a_t) - \left( r_{t+1} + \gamma \mathbb{E}[q_t(s_{t+1}, A)] \right) \right], \\
q_{t+1}(s, a) = q_t(s, a), \quad \text{当 } (s, a) \neq (s_t, a_t),
\end{cases} $
+ n-step Sarsa：$ q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t(s_t, a_t) \left[ q_t(s_t, a_t) - \left( r_{t+1} + \gamma r_{t+2} + \dots + \gamma^n q_t(s_{t+n}, a_{t+n}) \right) \right] $

居于Sarsa和蒙特卡洛之间，更一般化的算法

## Q-learning算法
$ \begin{cases}
q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t(s_t, a_t) \left[ q_t(s_t, a_t) - \left( r_{t+1} + \gamma \max_{a \in \mathcal{A}} q_t(s_{t+1}, a) \right) \right], \\
q_{t+1}(s, a) = q_t(s, a), \quad \text{当 } (s, a) \neq (s_t, a_t),
\end{cases} $

可以直接估计最优动作值进而找到最优策略

+ **On-policy P.S Off-policy**

任何一个强化学习算法都会涉及两种策略，一种是行为策略，一种是目标策略。行为策略用于生成经验样本，目标策略不断更新，收敛至最优策略。当行为策略与目标策略相同时，算法被称为On-policy的，当他们不同时，算法被称为是Off=policy的。

+ Sarsa是On-policy的
+ 蒙特卡洛方法是On-policy的
+ Q-learning算法是Off-policy的，根本原因在于它旨在求解贝尔曼最优方程，而不是某一个给定策略的贝尔曼方程
+ 在线学习是指智能体在与环境交互的同时用生成的数据来更新值和策略，离线学习是指智能体不与环境交互，而是用预先收集的数据来更新值和策略。如果算法是Off-policy的，它既可以在线学习，也可以离线学习

| 算法 | TD 目标 $ \bar{q}_t $ 的表达式 |
| --- | --- |
| Sarsa | $ \bar{q}_t = r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1}) $ |
| $ n $-step Sarsa | $ \bar{q}_t = r_{t+1} + \gamma r_{t+2} + \dots + \gamma^n q_t(s_{t+n}, a_{t+n}) $ |
| Q-learning | $ \bar{q}_t = r_{t+1} + \gamma \max_a q_t(s_{t+1}, a) $ |
| Monte Carlo | $ \bar{q}_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \dots $ |


| 算法 | 求解的数学方程 |
| --- | --- |
| Sarsa | BE: $ q_\pi(s, a) = \mathbb{E}\left[ R_{t+1} + \gamma q_\pi(S_{t+1}, A_{t+1}) \mid S_t = s, A_t = a \right] $ |
| $ n $-step Sarsa | BE: $ q_\pi(s, a) = \mathbb{E}\left[ R_{t+1} + \gamma R_{t+2} + \dots + \gamma^n q_\pi(S_{t+n}, A_{t+n}) \mid S_t = s, A_t = a \right] $ |
| Q-learning | BOE: $ q(s, a) = \mathbb{E}\left[ R_{t+1} + \gamma \max_a q(S_{t+1}, a) \mid S_t = s, A_t = a \right] $ |
| Monte Carlo | BE: $ q_\pi(s, a) = \mathbb{E}\left[ R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots \mid S_t = s, A_t = a \right] $ |


# Lesson8.值函数方法

> **核心思想**：这一章的重要思想在于将状态值/动作值改为函数表示而非表格表示，进而RM算法的更新目标变为了参数w。

## 基于值函数的时序差分算法：状态值估计
+ 目标函数：$ J(w) = \mathbb{E}\left[ \left( v_\pi(S) - \hat{v}(S, w) \right)^2 \right] $
    - S是一个随机变量，可以使用均匀分布，也可以使用平稳分布
    - 要使$ J(w) $最小，使用梯度下降法，最终化简得到$ w_{k+1} = w_k + 2\alpha_k \mathbb{E}\left[ \left( v_\pi(S) - \hat{v}(S, w_k) \right) \nabla_w \hat{v}(S, w_k) \right] $
    - 上式算法无法直接使用，因为需要真实期望值，可以用随机梯度代替真实梯度：$ w_{t+1} = w_t + \alpha_t \left( v_\pi(s_t) - \hat{v}(s_t, w_t) \right) \nabla_w \hat{v}(s_t, w_t) $
    - 上式依旧无法直接使用，因为需要真实状态值$ v_{\pi} $，可以用两种方法替换
        * 蒙特卡罗方法：$ w_{t+1} = w_t + \alpha_t \left( g_t - \hat{v}(s_t, w_t) \right) \nabla_w \hat{v}(s_t, w_t) $
        * 时序差分方法：$ w_{t+1} = w_t + \alpha_t \left[ r_{t+1} + \gamma \hat{v}(s_{t+1}, w_t) - \hat{v}(s_t, w_t) \right] \nabla_w \hat{v}(s_t, w_t) $

## 基于值函数的时序差分：动作值估计
基于值函数的Sarsa：$ w_{t+1} = w_t + \alpha_t \left[ r_{t+1} + \gamma \hat{q}(s_{t+1}, a_{t+1}, w_t) - \hat{q}(s_t, a_t, w_t) \right] \nabla_w \hat{q}(s_t, a_t, w_t) $

基于值函数的Q-learning：$ w_{t+1} = w_t + \alpha_t \left[ r_{t+1} + \gamma \max_{a \in \mathcal{A}(s_{t+1})} \hat{q}(s_{t+1}, a, w_t) - \hat{q}(s_t, a_t, w_t) \right] \nabla_w \hat{q}(s_t, a_t, w_t) $

## 深度Q-learning
目标函数：$ J = \mathbb{E}\left[ \left( R + \gamma \max_{a \in \mathcal{A}(S')} \hat{q}(S', a, w) - \hat{q}(S, A, w) \right)^2 \right] $



+ 可以看到，参数w不仅出现在$ \hat{q}(S, A, w) $中，还出现在$ y = R + \gamma \max_{a \in \mathcal{A}(S')}\hat{q}(S', a, w) $中；梯度很难计算。因此可假设**y 中 w 的值在短时间内是不变的**，就可以较容易地计算梯度。
+ 引入两个网络，一个是用于表示$ \hat{q}(s, a, w) $的主网络，一个是用于表示$ \hat{q}(S, A, w_T) $的目标网络，这样目标函数变为：$ J = \mathbb{E}\left[ \left( R + \gamma \max_{a \in \mathcal{A}(S')} \hat{q}(S', a, w_T) - \hat{q}(S, A, w) \right)^2 \right] $
+ 当$ w_T $固定不变时，J的梯度为$ \nabla_w J = -\mathbb{E}\left[ \left( R + \gamma \max_{a \in \mathcal{A}(S')} \hat{q}(S', a, w_T) - \hat{q}(S, A, w) \right) \nabla_w \hat{q}(S, A, w) \right] $
+ 每次迭代从回放缓冲区抽取一小批次样本，主网络输出$ \hat{q}(s, a, w) $，目标值为$ y_T \doteq r + \gamma \max_{a \in \mathcal{A}(s')} \hat{q}(s', a, w_T) $，主网络更新目的是最小化这两者的误差$ \sum (y - y_T)^2 $
+ 每次迭代都会更新主网络，但目标网络并非每次都更新，而是隔一段时间的迭代后更新为与主网络相同的参数
+ 经验回放：收集一些经验样本后，将它们存储在一个成为回放缓冲区的集合中，每次更新主网络时，从回放缓冲区抽取小批量的经验样本，抽取服从均匀分布。

# Lesson9.策略梯度方法

> **核心思想**：引入使用函数表示策略的方法，定义目标函数并通过梯度上升方法更新策略。

## 目标函数：定义最优策略
+ 目标函数一：$ \bar{v}_\pi = \mathbb{E}_{s \sim d} \left[ v_\pi(s) \right] $
    - 等价形式：$ J(\theta) = \lim_{n \to \infty} \mathbb{E}\left[ \sum_{t=0}^{n} \gamma^t R_{t+1} \right] = \mathbb{E}\left[ \sum_{t=0}^{\infty} \gamma^t R_{t+1} \right] $
    - $ \bar{v}_\pi = d^\mathsf{T} v_\pi $
+ 目标函数二：$ \bar{r}_\pi \doteq \sum_{s \in \mathcal{S}} d_\pi(s) r_\pi(s)
= \mathbb{E}_{S \sim d_\pi} \left[ r_\pi(S) \right], $
    - $ r_\pi(s) \doteq \sum_{a \in \mathcal{A}} \pi(a|s, \theta) r(s, a)
= \mathbb{E}_{A \sim \pi(s, \theta)} \left[ r(s, A) \middle| s \right] $
    - 等价形式：$ J(\theta) = \lim_{n \to \infty} \frac{1}{n} \mathbb{E}\left[ \sum_{t=0}^{n-1} R_{t+1} \right] $
    - $ \bar{r}_\pi = \sum_{s \in \mathcal{S}} d_\pi(s) r_\pi(s) = d_\pi^\mathsf{T} r_\pi $
+ 实际上这两个目标函数在γ<1时是等价的，因为$ \bar{r}_\pi = (1 - \gamma) \bar{v}_\pi $

## 梯度上升算法
+ 策略梯度定理：$ \nabla_\theta J(\theta) = \sum_{s \in \mathcal{S}} \eta(s) \sum_{a \in \mathcal{A}} \nabla_\theta \pi(a|s, \theta) q_\pi(s, a) $
    - 等价形式：$ \nabla_\theta J(\theta) = \mathbb{E}_{S \sim \eta, A \sim \pi(S, \theta)} \left[ \nabla_\theta \ln \pi(A|S, \theta) q_\pi(S, A) \right] $
    - 自然对数要求所有$ \pi(a|s,\theta)>0 $,因此要求这个策略必须随机且探索，可以通过 Softmax 实现
+ 梯度上升算法：$ \theta_{t+1} = \theta_t + \alpha \nabla_\theta J(\theta_t) = \theta_t + \alpha \mathbb{E}\left[ \nabla_\theta \ln \pi(A|S, \theta_t) q_\pi(S, A) \right] $
    - 由于有期望，无法直接求得
    - 使用蒙特卡罗算法（Reinforce 算法）：$ \theta_{t+1} = \theta_t + \alpha \nabla_\theta \ln \pi(a_t|s_t, \theta_t) q_t(s_t, a_t) $

- 可重写为：$ \theta_{t+1} = \theta_t + \alpha \left( \frac{q_t(s_t, a_t)}{\pi(a_t|s_t, \theta_t)} \right) \nabla_\theta \pi(a_t|s_t, \theta_t), \quad \underbrace{\left( \frac{q_t(s_t, a_t)}{\pi(a_t|s_t, \theta_t)} \right)}_{\beta_t} $
    - 当 $ \beta_t \ge 0 $ 时，$ \pi(a_t|s_t, \theta_{t+1}) \ge \pi(a_t|s_t, \theta_t) $；当 $ \beta_t < 0 $ 时，$ \pi(a_t|s_t, \theta_{t+1}) < \pi(a_t|s_t, \theta_t) $
    - 从$ \beta_t $的数学角度看，倾向于利用具有更大价值的动作和探索之前概率低的动作

# Lesson10.演员-批评家方法

> **核心思想**：策略梯度方法中策略的更新需要先得知动作值，可以通过蒙特卡罗和时序差分的方法，通过时序差分法得到动作值并进一步更新策略的算法就是 Actor-Critic 方法；通过引入基准函数来降低采样的方差，得到了优势演员-评论家算法；接下来通过重要性采样得到 Off-policy 版本；最后将随机策略变为确定性策略。

## 基础的 Actor-Critic 方法
初始化：一个策略函数 $ \pi(a|s,\theta_0) $，其中$ \theta_0 $是初始参数。一个价值函数$ q(s,a,w_0) $，其中$ w_0 $是初始参数。$ \alpha_w, \alpha_\theta > 0 $。

目标：学习一个最优策略来最大化 $ J(\theta) $。

在每个回合中的$ t $时刻

根据$ \pi(a|s_t,\theta_t) $产生$ a_t $，观测$ r_{t+1}, s_{t+1} $，然后根据$ \pi(a|s_{t+1},\theta_t) $ 生成$ a_{t+1} $

Actor（策略更新）：

$ \theta_{t+1} = \theta_t + \alpha_\theta \nabla_\theta \ln \pi(a_t|s_t,\theta_t) q(s_t,a_t,w_t) $

Critic（价值更新）：

$ w_{t+1} = w_t + \alpha_w \left[ r_{t+1} + \gamma q(s_{t+1},a_{t+1},w_t) - q(s_t,a_t,w_t) \right] \nabla_w q(s_t,a_t,w_t) $

| 初始化 | 一个策略函数 $ \pi(a \mid s,\theta_0) $，其中$ \theta_0 $是初始参数。一个价值函数$ q(s,a,w_0) $，其中$ w_0 $是初始参数。$ \alpha_w, \alpha_\theta > 0 $ |
| :---: | :---: |
| 目标 | 学习一个最优策略来最大化 $ J(\theta) $ |
| 流程 | 在每个回合中的$ t $时刻：<br/>1. 根据$ \pi(a \mid s_t,\theta_t) $产生$ a_t $，观测$ r_{t+1}, s_{t+1} $，然后根据$ \pi(a \mid s_{t+1},\theta_t) $ 生成$ a_{t+1} $<br/>2. Actor（策略更新）：<br/>$ \theta_{t+1} = \theta_t + \alpha_\theta \nabla_\theta \ln \pi(a_t \mid s_t,\theta_t) q(s_t,a_t,w_t) $<br/>3. Critic（价值更新）：<br/>$ w_{t+1} = w_t + \alpha_w \left[ r_{t+1} + \gamma q(s_{t+1},a_{t+1},w_t) - q(s_t,a_t,w_t) \right] \nabla_w q(s_t,a_t,w_t) $ |


## 优势演员-评论家
+ 策略梯度的重要性质：（**对额外基准不变**）$ \mathbb{E}_{S \sim \eta, A \sim \pi}\left[\nabla_{\theta} \ln \pi(A|S, \theta_t) q_\pi(S, A)\right] = \mathbb{E}_{S \sim \eta, A \sim \pi}\left[\nabla_{\theta} \ln \pi(A|S, \theta_t)\left(q_\pi(S, A) - b(S)\right)\right] $
+ 引入基准函数的意义是在使用随机样本近似真是梯度时减少近似的方差
+ 事实上能够最小化方差的最优基准：$ b^{*}(s) = \frac{\mathbb{E}_{A \sim \pi}\left[\left\|\nabla_{\theta} \ln \pi\left(A | s, \theta_{t}\right)\right\|^{2} q_{\pi}(s, A)\right]}{\mathbb{E}_{A \sim \pi}\left[\left\|\nabla_{\theta} \ln \pi\left(A | s, \theta_{t}\right)\right\|^{2}\right]}, \quad s \in \mathcal{S}.
 $
+ 由于上式过于复杂，从式中移除权重，可以得到一个次优的基准：$ b^{\dagger}(s) = \mathbb{E}_{A \sim \pi}\left[q_{\pi}(s, A)\right] = v_{\pi}(s), \quad s \in \mathcal{S}. $

实际上，这个次优的基准函数就是状态值函数

+ 当 $ b(s) = v_{\pi}(s) $ 时，式(10.1)中的梯度上升算法变成了

$ \begin{aligned}
\theta_{t+1} &= \theta_t + \alpha \mathbb{E}\left[\nabla_{\theta} \ln \pi(A|S, \theta_t)\left[q_{\pi}(S, A) - v_{\pi}(S)\right]\right] \\
&\doteq \theta_t + \alpha \mathbb{E}\left[\nabla_{\theta} \ln \pi(A|S, \theta_t) \delta_{\pi}(S, A)\right].
\end{aligned} $

其中$ \delta_{\pi}(S, A) $被称为优势函数，$ \delta_{\pi}(S, A)>0 $意味着相应的动作值大于平均值

+ 如果把上式的真实梯度替换为随机梯度，可以得到：$ \begin{aligned}
\theta_{t+1} &= \theta_t + \alpha \nabla_\theta \ln \pi(a_t|s_t, \theta_t)\left[q_t(s_t, a_t) - v_t(s_t)\right] \\
&= \theta_t + \alpha \nabla_\theta \ln \pi(a_t|s_t, \theta_t) \delta_t(s_t, a_t).
\end{aligned} $

如果动作值和状态值时通过蒙特卡洛方法估计的，那么该式被称为带基准的 			REINFORCE。如果是通过时序差分方法估计的，那么这种算法被称为 Advantage Actor-Critic

## 异策略演员-评论家
如果已经有一些由其他行为策略生成的样本，策略梯度方法仍然可以使用这些样本来得到最优策略，就变成 Off-policy 方法，另外还需要采用**重要性采样**技术

+ **重要性采样**：$ \mathbb{E}_{X \sim p_0}[X] = \sum_{x \in \mathcal{X}} p_0(x) x = \sum_{x \in \mathcal{X}} p_1(x) \frac{p_0(x)}{p_1(x)} x = \mathbb{E}_{X \sim p_1}[f(X)], \quad \underbrace{\frac{p_0(x)}{p_1(x)}}_{f(x)} $

通过这个式子，将估计$ \mathbb{E}_{X \sim p_0}[X] $的问题转换为估计$ \mathbb{E}_{X \sim p_1}[f(X)] $的问题，进而有

$ \mathbb{E}_{X \sim p_0}[X] = \mathbb{E}_{X \sim p_1}[f(X)] \approx \bar{f} = \frac{1}{n} \sum_{i=1}^n f(x_i) = \frac{1}{n} \sum_{i=1}^n \frac{p_0(x_i)}{p_1(x_i)} x_i, \quad \underbrace{\frac{p_0(x_i)}{p_1(x_i)}}_{\text{重要性权重}} $

+ Off-policy 策略梯度定理

目标是使用行为策略 β 生成的样本来得到一个目标策略 $ \pi $，从而最大化目标函数		$ J(\theta) = \sum_{s \in S} d_\beta(s) v_\pi(s) = \mathbb{E}_{S \sim d_\beta} \left[ v_\pi(S) \right] $

如果 γ∈(0,1)，Off-policy 梯度为：											$ \nabla_\theta J(\theta) = \mathbb{E}_{S \sim \rho, A \sim \beta} \left[ \underbrace{\frac{\pi(A|S,\theta)}{\beta(A|S)}}_{\text{重要性权重}} \nabla_\theta \ln \pi(A|S,\theta) q_\pi(S,A) \right] $

其中状态分布 ρ 为:$ \rho(s) \doteq \sum_{s' \in S} d_\beta(s') \mathrm{Pr}_\pi(s|s'), \quad s \in S. $		

- Off-policy 策略梯度对额外的基准函数 b(s)也是不变的，为降低估计方差，可以选择基准函数为$ v_{\pi}(S) $，对应策略梯度算法为$ \theta_{t+1} = \theta_t + \alpha_\theta \frac{\pi(a_t|s_t,\theta_t)}{\beta(a_t|s_t)} \nabla_\theta \ln \pi(a_t|s_t,\theta_t) \left( q_t(s_t,a_t) - v_t(s_t) \right) $
- 优势函数可以被时序差分误差代替$ q_t(s_t,a_t) - v_t(s_t) \approx r_{t+1} + \gamma v_t(s_{t+1}) - v_t(s_t) \doteq \delta_t(s_t,a_t) $，就变成了：$ \theta_{t+1} = \theta_t + \alpha_\theta \frac{\pi(a_t|s_t,\theta_t)}{\beta(a_t|s_t)} \nabla_\theta \ln \pi(a_t|s_t,\theta_t) \delta_t(s_t,a_t) $

## 确定性演员-评论家
本节使用确定性的策略表示：$ a=\mu(s,\theta) $

+ 确定性策略梯度定理：$ \begin{aligned}
\nabla_\theta J(\theta) &= \sum_{s \in S} \eta(s) \nabla_\theta \mu(s) \left. \left( \nabla_a q_\mu(s,a) \right) \right|_{a=\mu(s)} \\
&= \mathbb{E}_{S \sim \eta} \left[ \left. \nabla_\theta \mu(S) \left( \nabla_a q_\mu(S,a) \right) \right|_{a=\mu(S)} \right]
\end{aligned} $
+ 目标函数一：$ J(\theta) = \mathbb{E}\left[v_\mu(s)\right] = \sum_{s \in S} d_0(s) v_\mu(s) $
    - 梯度：$ \begin{aligned}
\nabla_\theta J(\theta) &= \sum_{s \in S} \rho_\mu(s) \nabla_\theta \mu(s) \left. \left( \nabla_a q_\mu(s,a) \right) \right|_{a=\mu(s)} \\
&= \mathbb{E}_{S \sim \rho_\mu} \left[ \left. \nabla_\theta \mu(S) \left( \nabla_a q_\mu(S,a) \right) \right|_{a=\mu(S)} \right],
\end{aligned} $
+ 目标函数二：$ \begin{aligned}
J(\theta) &= \bar{r}_\mu = \sum_{s \in S} d_\mu(s) r_\mu(s) = \mathbb{E}_{S \sim d_\mu} \left[ r_\mu(S) \right]
\end{aligned} $
    - 梯度：$ \begin{aligned}
\nabla_\theta J(\theta) &= \sum_{s \in S} d_\mu(s) \nabla_\theta \mu(s) \left. \left( \nabla_a q_\mu(s,a) \right) \right|_{a=\mu(s)} \\
&= \mathbb{E}_{S \sim d_\mu} \left[ \left. \nabla_\theta \mu(S) \left( \nabla_a q_\mu(S,a) \right) \right|_{a=\mu(S)} \right]
\end{aligned} $
+ 梯度上升算法：$ \theta_{t+1} = \theta_t + \alpha_\theta \mathbb{E}_{S \sim \eta} \left[ \left. \nabla_\theta \mu(S) \left( \nabla_a q_\mu(S,a) \right) \right|_{a=\mu(S)} \right] $
    - 随机梯度上升算法：$ \theta_{t+1} = \theta_t + \alpha_\theta \left. \nabla_\theta \mu(s_t) \left( \nabla_a q_\mu(s_t,a) \right) \right|_{a=\mu(s_t)} $
